# C-15-puzzle-game

## Основная информация 

 Интерактивная игра в пятнашки. Игровое поле генерируется случайным образом, однако, правильное расположение должно быть достижимым из сгенерированного.

 Каждый ход игрока (перемещение костяшки) фиксируется. Имеется возможность отмены выполненных действий.

 История действий игрока представлена с помощью логической структуры данных «стек».

 Реализация стека на основе вектора предполагает удаление из него наиболее старой записи в случае возникновения переполнения.

## Критерий решаемости:

1. **Для поля нечётного размера:**
   * Количество инверсий должно быть чётным, чтобы головоломка была решаемой.
   * Положение пустой клетки не влияет на решаемость.

2. **Для поля чётного размера:**
   * Количество инверсий должно быть чётным, если пустая клетка находится на нечётной строке снизу.
   * Количество инверсий должно быть нечётным, если пустая клетка находится на чётной строке снизу.
